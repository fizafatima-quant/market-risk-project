# market-risk-project

# Market Risk Modelling and Backtesting in Python

## Research question

How do historical and normal parametric risk estimates differ for a diversified portfolio, and how well does a rolling Historical VaR model forecast losses?

## Portfolio and methods

This project analyses an equally weighted portfolio of SPY, VGK and GLD using daily market data. The notebook covers data cleaning, logarithmic returns, portfolio performance, correlation, Value at Risk (VaR), Expected Shortfall (ES), return-distribution analysis and rolling VaR backtesting.

## Key findings

- At 99% confidence, Historical VaR was **2.3900%**, compared with **1.9331%** for Normal Parametric VaR.
- Portfolio returns had excess kurtosis of **5.2788**, consistent with heavier tails than a normal distribution.
- The rolling 95% Historical VaR model had **77 exceptions in 1,170 forecasts**, an observed rate of **6.58%** versus the expected **5%**.
- The Kupiec test gave a p-value of **0.0177**, rejecting the expected exception rate at the 5% significance level.
- Model evaluation changed with the estimation window and evaluation period.

## Repository contents

- `notebooks/market_risk_analysis.ipynb` — complete analysis and interpretation
- `data/` — cleaned prices, returns and risk-comparison results
- `figures/` — charts generated by the notebook

## Limitations

The results depend on the selected assets and sample period. Normal Parametric VaR does not fully represent the observed heavy tails. The Kupiec test assesses overall exception frequency, not whether exceptions cluster. The analysis does not include transaction costs, liquidity effects or currency risk for a euro-based investor.

This is an educational modelling project, not investment advice.
